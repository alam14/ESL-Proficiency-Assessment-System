# ESL Proficiency Assessment System

This assignment is a web-based ESL Proficiency Assessment System developed using Python and Flask.

## Features
- Student registration
- ESL test with 8 questions
- Automatic grading
- ESL level assignment
- Result report generation
- SQLite database storage

## Technologies Used
- Python
- Flask
- SQLite
- HTML/CSS
